## 새 버전 설계 시 유의점

**이어받을 것 (정체성 축)**

- 카테고리 `소셜 네트워킹` 유지 — 케미 그룹은 이 카테고리에 자연스럽다.
- 앱 설명의 프레임: "아이스 브레이킹으로 비슷한 사람을 찾는 소모임 플랫폼",
  "익명으로 진행되어 프라이버시 보장". 케미 그룹이 그대로 이 문장 안에 들어간다.
- 코드 구조상의 연결점: MeSo 의 `domain/meetups/`(모임) → 케미 그룹,
  `CoinPage`/`CoinLedgerPage`(코인 경제) → 동일 구조 유지.

**반드시 바꿔야 하는 것 (사실 진술 축)**

- 스크린샷·설명 — 실제 앱과 일치해야 한다. 유지 불가.
- 개인정보 라벨 — MeSo 는 위치 수집을 선언했으나 facely 는 수집하지 않는다.
  얼굴 데이터 수집은 새로 선언해야 한다.
- **연령 등급 17+** — MeSo 기준이다. facely 기준으로 재산정 필요.
- **마케팅 URL / 지원 URL** — 현재 비어 있다. `https://facely.kr` 로 설정해야
  AdMob 의 `app-ads.txt` 인증이 통과된다 (PLAN.md 7-c).
- **영어 현지화** — 리스팅에 영어가 등록돼 있다. 새 버전에서 영어 메타데이터를
  갱신하거나 영어 현지화를 제거해야 한다. 방치하면 MeSo 시절 영어 설명이 그대로
  남는다.
