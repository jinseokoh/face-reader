# ASC 전용 필드 백업

공개 API 에 노출되지 않아 App Store Connect 에서 직접 복사한 항목.

수집일 2026-08-14

## 키워드

```
소모임, 만남, 모임, 관심사, 데이트, 데이팅, 소셜, 주제, 친구, 익명, 채팅, 미소, MeSo, Meet Socrates
```

관찰:

- `데이트` / `데이팅` 이 들어 있다. 4.3(b) 조문이 dating 을 포화 카테고리 예시로
  명시하므로 새 버전에서는 제거 대상이다.
- `소모임` / `모임` / `친구` / `익명` / `채팅` 은 케미 그룹과 그대로 이어진다.
  유지할 만한 축이다.
- `미소` / `MeSo` / `Meet Socrates` 는 구 브랜드 토큰이다. 이름을 언제 바꾸느냐에
  따라 처리 시점이 갈린다.

> 잘려 나간 텍스트로 보인다. 새 버전에 옮기지 않는다.

## 아직 수집 안 된 항목

새 버전 편집을 시작하기 전에 ASC 에서 복사해 이 파일에 추가할 것.

- [ ] 부제 (Subtitle)
- [ ] 프로모션 텍스트
- [ ] 심사 정보 — 연락처, 데모 계정, 메모

영어 현지화는 백업하지 않는다. MeSo 는 **한국 스토어에만** 등록돼 있고
(us·jp·gb 조회 결과 0건), 영어 메타데이터는 새로 쓰거나 현지화 자체를 삭제하면
된다. MeSo 시절 영어 설명을 그대로 남겨두는 것만 피하면 된다.
